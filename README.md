# onegai\_

# program ini membutuhkan node.js dan redis server untuk berjalan

1. ubah file env menjadi .env
2. install terlebih dahulu node.js
3. lakukan perintah terminal (cmd) npm -i
4. install redis server (file redis tersedia di folder root program ini)
5. dalam file .env atur secret= kata sandi yang diinginkan
6. untuk menjalankan program bisa menggunakan perintah "node ." atau menggunakan nodemon
7. terima kasih banyak.
